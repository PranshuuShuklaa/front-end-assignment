What is HTML?

HTML means HyperText Markup Language. It gives a webpage its structure, such as headings, paragraphs, links, images, and forms. The browser reads the tags and displays the result.

Each example shows the tag, its job, a common syntax pattern, useful attributes, and the browser output.

THE EXAMPLES

HTML tag reference

Each example shows what a tag does, a basic syntax, common attributes, and the result in a browser.

01<html> <head> <body>STRUCTURE

Document structure

These tags form the basic frame of an HTML page. The head stores page information, while the body contains visible content.

Syntax<!doctype html> <html lang="en"> <head>...</head> <body>...</body> </html>
Attributeslang on html; charset and name on meta; href on link
BROWSER OUTPUT

The browser displays the page title in its tab and the page heading below.

My first webpageHello, class!
02<h1> to <h6>TEXT

Headings

Headings name the page and its sections. Use them in order to make the content easier to scan.

Syntax<h1>Main heading</h1>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT

A clear page heading

03<p>TEXT

Paragraph

Groups sentences into a block of regular text. Browsers add space around each paragraph.

Syntax<p>Write a sentence here.</p>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT

A paragraph keeps related sentences together. This is a second sentence.

04<strong> <em> <mark>TEXT

Text emphasis

Marks important text, spoken emphasis, or a highlighted passage. These tags add meaning as well as style.

Syntax<strong>Important</strong> <em>emphasis</em> <mark>highlight</mark>
AttributesGlobal attributes
BROWSER OUTPUT

Important, emphasized, highlighted

05<a>LINKS

Link

Creates a link to another page, a file, or a place on the current page.

Syntax<a href="https://example.com">Visit the site</a>
Attributeshref is required for a destination; target and rel are also common
BROWSER OUTPUTRead the HTML guide on MDN
06<img>MEDIA

Image

Places an image in the page. The descriptive alt text helps screen-reader users and appears if the image cannot load.

Syntax<img src="photo.jpg" alt="A short description">
Attributessrc, alt, width, height, loading
BROWSER OUTPUT
07<ul> <li>LISTS

Unordered list

Shows related items where the order does not matter. Put each item inside an <li>.

Syntax<ul><li>Item</li></ul>
AttributesGlobal attributes; list items can use value in an ordered list
BROWSER OUTPUT
  • Notebook
  • Pencil
  • Ruler
08<ol>LISTS

Ordered list

Shows steps or items where the order matters. Browsers number the list automatically.

Syntax<ol><li>First step</li></ol>
Attributesstart, reversed, and type
BROWSER OUTPUT
  1. Write the HTML
  2. Open it in a browser
  3. Check the result
09<table> <tr> <th> <td>TABLES

Table

Displays information in rows and columns. Use tables for data, not to arrange a webpage.

Syntax<table><tr><th>...</th></tr><tr><td>...</td></tr></table>
Attributesscope on headings; colspan and rowspan on cells
BROWSER OUTPUT
TagPurpose
<p>Text
<a>Links
10<form>FORMS

Form

Groups controls that collect information from a visitor. The browser checks the required field, then adds the entered name to the page address when the form is submitted.

Syntax<form action="/submit" method="post">...</form>
Attributesaction, method, autocomplete
BROWSER OUTPUT
11<input>FORMS

Input

Creates a field for a short answer. Its type tells the browser what kind of information to expect.

Syntax<input type="email" name="email" placeholder="you@example.com">
Attributestype, name, placeholder, required, value
BROWSER OUTPUT
12<button>FORMS

Button

Creates a clickable control. A button needs a form or JavaScript to perform an action; this example shows a regular button.

Syntax<button type="button">Click me</button>
Attributestype, disabled, name, and value
BROWSER OUTPUT
13<label> <select>FORMS

Label and dropdown

A label names a control. A select menu lets the visitor choose from a set of options.

Syntax<label for="topic">Topic</label> <select id="topic"><option>HTML</option></select>
Attributesfor on label; name, required, and multiple on select
BROWSER OUTPUT
14<audio>MEDIA

Audio

Embeds a sound clip with browser playback controls. This sample is hosted online, so it needs an internet connection.

Syntax<audio controls src="sound.mp3"></audio>
Attributessrc, controls, loop, muted, preload
BROWSER OUTPUT
15<video>MEDIA

Video

Embeds a video clip. The controls let a visitor play, pause, and adjust the volume. This sample needs internet access.

Syntax<video controls src="clip.mp4"></video>
Attributessrc, controls, poster, width, muted, loop
BROWSER OUTPUT
16<header>SEMANTIC

Header

Introduces a page or a section. It often contains a title, logo, or introductory information.

Syntax<header><h2>Page title</h2></header>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT

Science Club

Ideas, experiments, and discoveries

17<nav>SEMANTIC

Navigation

Groups the main links that help visitors move around a page or website.

Syntax<nav aria-label="Main"><a href="#home">Home</a></nav>
AttributesGlobal attributes; aria-label can describe the navigation
BROWSER OUTPUT
AboutActivitiesContact
18<main>SEMANTIC

Main content

Wraps the page's central content. A page should have one main element, separate from its header and footer.

Syntax<main><h1>Page content</h1></main>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT
Today's lesson

The main element holds the central topic of this page.

19<section>SEMANTIC

Section

Groups related content under one topic. A section usually has its own heading.

Syntax<section><h2>Topic</h2>...</section>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT

Art supplies

Paper, paint, and brushes

20<article>SEMANTIC

Article

Contains a complete piece of content that could make sense on its own, such as a news story or post.

Syntax<article><h2>Story title</h2><p>...</p></article>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT

Class garden opens

Students planted herbs in the school garden.

21<footer>SEMANTIC

Footer

Closes a page or section with information such as authorship, contact details, or related links.

Syntax<footer><p>Written by Alex</p></footer>
AttributesGlobal attributes, such as id and class
BROWSER OUTPUT
Written by Alex | Class project
22<br>TEXT

Line break

Starts a new line inside text, such as an address or a poem. It does not need a closing tag.

SyntaxFirst line<br>Second line
AttributesNo tag-specific attributes; global attributes can apply
BROWSER OUTPUT

Room 12
North Hall

23<blockquote>TEXT

Block quote

Marks a longer quotation from another source. Use cite to give the source URL.

Syntax<blockquote cite="https://example.com">A quotation.</blockquote>
Attributescite, the URL of the source
BROWSER OUTPUT
Learning is easier when you can see an example.
24<textarea>FORMS

Multi-line input

Creates a text field for a longer answer, such as a comment or message.

Syntax<textarea name="message" rows="3"></textarea>
Attributesname, rows, cols, placeholder, required
BROWSER OUTPUT

PUT IT TOGETHER

A basic HTML page

This is a small starting point. Save it as index.html and open it in a browser.

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My page</title>
  </head>
  <body>
    <h1>Hello, class!</h1>
    <p>This is my first page.</p>
  </body>
</html>
